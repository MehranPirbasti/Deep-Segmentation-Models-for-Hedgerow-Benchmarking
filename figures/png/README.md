# Figures

## What is here

The 22 plots of the manuscript, at 600 dpi, together with their editable vector
versions in `../vector/`. Every one is drawn from `../../data/` by
`../../analysis/build_v6.py`.

## What is deliberately absent

Five figures of the manuscript are **not** in this repository:

| Figure | Why |
|---|---|
| `Study_Area` | contains Pleiades Neo imagery |
| `Proxy_Annotation_Update` | contains Pleiades Neo imagery |
| `Quantitative_Overlays` | contains Pleiades Neo imagery |
| `Qualitative_Overlays` | contains Pleiades Neo imagery |
| `Heterogeneous_Conditions_Panel` | contains Pleiades Neo imagery |

The imagery is licensed by Airbus Defence and Space. The license permits small
non-georeferenced extracts to be embedded in a report or PDF with the credit
displayed, which is what the manuscript does. It does not permit publishing the
imagery as standalone files, and three of these composites exceed the size at
which a single extract is defined in any case.

They are therefore available only in the published article. Nothing in this
repository depends on them: no figure data, no table, and no reported number.
